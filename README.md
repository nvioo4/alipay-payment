## 搬瓦工支持哪些付款方式

BandwagonHost（搬瓦工）是 IT7 旗下的 VPS 品牌，结账页面目前提供四种付款方式：

- **Alipay（支付宝）**：国内用户最常用，扫码或登录支付宝账户直接用人民币结算
- **UnionPay（银联）**：国内储蓄卡、信用卡
- **PayPal**：海外用户常用
- **Credit Card（信用卡）**：Visa、Mastercard 等国际信用卡

有两个容易踩坑的点需要单独说。

**第一，账户余额充值（Add Funds）不支持支付宝。** 想往搬瓦工账户里充值余额，只能用 PayPal 或信用卡，支付宝只在购买套餐和支付续费账单时可用。

**第二，付款方式的展示不是一成不变的。** 各家教程里提到的组合略有出入——有的记录了微信支付，有的提到银联一度下线过。搬瓦工的支付宝通道走的是第三方支付网关 Payssion，接口会不定期调整。结账时以页面实际显示为准，这比任何攻略都可靠。

## 支付宝付款的完整步骤

整个流程从选套餐到付款完成，通常十分钟以内能搞定。步骤如下：

1. **选择套餐**：在套餐列表里选好配置，点击进入购买页
2. **选机房和周期**：同一个套餐往往对应多个机房位置，KVM 系列还支持之后免费迁移
3. **填优惠码**：在 Promotional Code 一栏输入优惠码并点击验证，价格会直接刷新
4. **注册或登录账号**：填邮箱、设置密码，资料建议如实填写
5. **选择 Alipay**：在付款方式里点选支付宝
6. **验证信息**：输入支付宝邮箱，点击 Alipay 标签页后，按提示输入收到的验证码和身份证后 5 位
7. **跳转扫码**：页面跳转到支付宝后，用手机 App 扫码支付即可

付款完成后订单状态会自动更新，VPS 一般几分钟内开通。

**汇率怎么算？** 支付宝按实时牌价把美元金额换算成人民币扣款，搬瓦工本身不额外收手续费。你实际支付的人民币金额，以支付宝支付页面显示的为准。

## 支付宝付款失败了怎么办

这是搜索 BandwagonHost Alipay 的高频问题，处理思路比反复重试有用。

最常见的一种情况是：**支付宝已经扣款，但搬瓦工那边显示未付款。** 原因通常是付款后没有成功跳转回搬瓦工页面，支付网关没收到返回信息。这时候不要重新下单，先去账户后台找那张 unpaid 状态的账单，等一会儿或手动触发一次同步；确实卡住就提交工单，附上支付宝的支付凭证。

如果是支付宝界面白屏、跳转 404 或者一直转圈：

- 换浏览器，或用无痕模式重试
- 检查是不是本地网络问题导致 Payssion 通道加载失败
- 实在不行，临时换银联或 PayPal 完成支付——买套餐和续费都支持这几种方式，不用非在支付宝一棵树上吊着

大额支付时支付宝可能触发风控要求二次验证，小额通常没这个问题。

## 续费能用支付宝吗？会不会自动扣款？

两个问题一起回答。

**能用。** 不管你第一次付款用的是 PayPal 还是信用卡，续费账单都可以换成支付宝支付。生成续费账单后，进入账单页选择 Alipay，和首次购买流程基本一致。

**不会自动扣款。** 搬瓦工官方明确说明从不自动从你的支付方式中扣费，也不保存客户的支付信息。到期前系统会生成续费账单，你不主动付款，服务到期就停——没有“忘记关自动续费被扣一年”这种糟心事。也因为优惠码循环生效，续费时沿用同一个码即可继续享受折扣。

## 30天退款：支付宝付款原路退回

搬瓦工有 30 天退款政策，支付宝付款的退款会**原路退回支付宝账户**，不退到搬瓦工账户余额，也不收手续费。

拿到全额退款需要满足几个条件：

- 账户注册时间在 30 天内
- 之前没有申请过退款
- 账户下 VPS 总数少于 3 个，且总支付金额低于 100 美元
- VPS 的 IP 没有被封

退款通过提交工单办理，一般 24 小时内到账。反过来说，如果你打算先买一个月试试，30 天内不满意可以申请退款，试错成本基本为零——这也是很多人敢直接年付的原因。

**微信支付能用吗？** 有教程记录过搬瓦工曾支持微信支付，但近期的信息显示该选项并非一直可用。结账页面显示什么就用什么，支付宝通常都在。

**注册时要注意什么？** 注册账号时建议使用本地真实网络环境，地址信息如实填写，减少订单被标记异常的概率。付款失败的订单会以 unpaid 状态留在后台，补付即可，不必重新下单。

**人民币直接付吗？** 是的。订单金额是美元，支付宝支付时按实时汇率换算成人民币扣款，搬瓦工不额外加收手续费。
